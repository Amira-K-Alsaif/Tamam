# أسئلة تقييم مصنع المعرفة

50 سؤالًا طبيعيًا باللغة العربية مبنيًا على وثائق الشركة الوهمية في `data/company/`.

الحقول:
- `id`: رقم السؤال.
- `question`: سؤال المستخدم.
- `expected_document_id`: الوثيقة التي يُفترض أن يسترجعها النظام.
- `expected_answer_hint`: عبارة دالة موجودة في مصدر الإجابة للتحقق الأولي.

**هذه بيانات تقييم مرجعية وليست نتائج RAGAS**. لم يُشغّل نموذج لاسترجاعها أو الإجابة عنها بعد.
