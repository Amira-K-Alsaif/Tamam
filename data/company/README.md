# شركة نخلة للتقنية — بيانات تجريبية

هذه شركة **وهمية بالكامل** لا تمثل سياسة جهة حقيقية. صُممت لاختبار «تمّام» فقط.

- `company_profile.json`: تعريف الشركة وأقسامها.
- `manifest.json`: سجل الوثائق بالحقول المتفق عليها في `docs/team.md`.
- `documents/`: 28 وثيقة عربية Markdown، تشمل سياسات وإجراءات ونماذج وأسئلة شائعة.

المعلومة المعتمدة للعرض التجريبي: الإجازة السنوية تُطلب قبل 14 يومًا، ويعتمدها المدير خلال يومي عمل، والتسليم مطلوب عند تجاوز خمسة أيام عمل. العمل عن بعد يومان أسبوعيًا وفق سياسة 28 أكتوبر.

لا تستخدموا هذه الوثائق للفتوى النظامية أو في أي شركة حقيقية.
